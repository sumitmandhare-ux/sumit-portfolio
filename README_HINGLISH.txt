SUMIT PORTFOLIO WEBSITE — HOW TO RUN AND HOST
================================================
Files:
- index.html: website content
- style.css: website design
- script.js: mobile menu and footer year

RUN ON YOUR LAPTOP
1. Extract this ZIP file.
2. Open the folder in VS Code, or double-click index.html to open in a browser.
3. Update your email and your own GitHub/LinkedIn links in index.html.
4. Review project descriptions and keep only truthful details.

HOST ON RENDER (matching the reference activity PDF)
1. Create a GitHub account and a new repository.
2. Upload index.html, style.css, and script.js.
3. Create/sign in to Render at https://render.com.
4. Choose New > Static Site and connect the GitHub repository.
5. For a plain HTML/CSS/JS site, no build command is required; set the publish directory to the repository root (often .).
6. Deploy and open the Render-provided URL to test.
7. Purchase a domain from a domain registrar; check first-year and renewal prices.
8. In Render, open the site's Custom Domains section and add your domain.
9. Follow Render's current instructions for the exact DNS records/nameservers at your registrar. Do not guess DNS values.
10. Wait for DNS verification, enable/confirm HTTPS, and test the site on mobile and desktop.

IMPORTANT
- This ZIP does not purchase a domain or publish the website automatically.
- Replace your.email@example.com and sample social links before publishing.
- Add the final domain URL to your activity report only after the domain is purchased, connected, and working.
